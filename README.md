# Tiny Chess Engine (tiny-chess-01)

An optimized chess engine in 4 KB of Python, built for the [make.fun](https://make.fun/bounty/tiny-chess-01) bounty.

## Description

`main.py` is the complete chess engine, keeping well within the 4,096-byte limit while implementing material evaluation, capture ranking, piece-square tables, and positional heuristics.
